# BEGINNERS GUIDE TO SOLIDITY (Understanding the Smart Contract)
Samuel Ojonugwa Adama
>Blockfuse Labs, 30-01-2025


>[!Tip] Introduction to Solidity, Smart Contracts, and understanding Function selectors, Visibility Specifiers and Glossary of Terms.

- #### smart contracts
 *smart contract is a program that executes on the Ethereum computing Infastructure.*
 
- #### Solidity
 *Solidity is a imperative (procedural) programming lanuguage with language that is similar to Javascript, C++ or Java.*
 
 With the aging industrial plant, it is important to understand these tools, and as well important to understand how Technology has evolved from Hardwares to Wearables and wave of the 4th Industrial revolution, with the disruptive innovation Technology like Blockchain, Artificial Intelligence, Quatum Computing and Robotics.
 
Solidity is programming language that is essential  admist blockchain enthusiast and Blockchain Developers. These smart contracts that is written on the blockchain network must be small and concise to be cost efficient, smart contracts must maintain clarity and be readable. It is advisable to maintain sizeable amount of code that can live on the blockchain. the recommendable size for a smart contract is *24kb*.

The cost for maintaining a smart contract is expensive so you pay 20,000bytes per 32bytes. This limit is enforced by EIP 170 Rule, this regulation is set to maintain the Gas Consumption.

#### What are Function Selectors?
 *Understanding Function selectors is essential for developers and enthusiast working with Ethereum Smart Contracts-ESC, as they form a strong backbone of how functions are invoked within these decentralised applications*
 
 Function selectors in solidity are crucial for identifying which function to be executed in a smart contract. function selectors are crucial for identifying which consists of the function name and its parameters types, formatted as a string.
 
 #### What are Visiblity Specifiers?
 *In Solidity, Visibility specifiers are essential for managing access to functions and state variables within smart contracts. There are four primary visiblity specifiers:*
 
 - Public:
   Functions and variables marked as public can be  accessed within the contract and externally by other contracts or accounts.
   
  - Private:
  Private functions and variables are only accessible within the contract that defines them. They cannot be accessed from derived contracts or externally.
  
  - Internal:
  Internal Functions and variables can be accessed within the defining contract and by derived contracts (subclasses).
  
  - External:
  External functions can only be called from other contracts or externally; they cannot be called internally by the contracts that defines them.
  
  In Conclusion, it is important to understand the future of technology, smart contracts and solidity.
